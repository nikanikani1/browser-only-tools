# Browser-only tools

A small collection of utilities that run entirely in the browser tab - nothing is uploaded, no accounts required.

## Developer tools

- **EncodeKit** - Base64 and URL encode/decode. UTF-8 safe, handles base64url and missing padding: https://base64kit.com/
- **XMLFormatter** - format / validate / minify XML with exact line and column errors: https://prettyxml.com/

## Other projects

- **HeadshotSnap** - AI headshots generated from five selfies: https://headshotsnap.com/
- **StemExtractor** - AI vocal remover and 4-stem separation: https://stemextractor.com/
- **TidyContracts** - contract risk check for freelancers: https://tidycontracts.com/
- **Fitout.hk** - Hong Kong renovation shortlist and pricing: https://fitout.hk/
- **Yuezi.hk** - Hong Kong postpartum care comparison: https://yuezi.hk/
